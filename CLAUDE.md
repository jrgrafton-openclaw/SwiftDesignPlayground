# Swift Design Playground

**Bundle ID:** com.jrgrafton.swift.design.playground

Use this repository strictly for SwiftUI single-view prototyping.
Avoid adding complex states or external dependencies unless necessary.
Always write and test changes using this project before syncing them with main apps (e.g. SingCoach).

### Fastlane
We use Fastlane to quickly push test builds natively on-device. Use `bundle exec fastlane` to push beta.
